# Zarik Studio

A Vite + React portfolio site prepared for Vercel deployment.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Environment variables

Set these in Vercel Project Settings → Environment Variables:

- `VITE_VAPI_PUBLIC_KEY`
- `VITE_VAPI_ASSISTANT_ID`
- `VITE_FORMSPREE_ID`
